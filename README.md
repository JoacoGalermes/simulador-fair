# Simulador FAIR

Simulador Monte Carlo de pérdida anual (FAIR) usado en un taller de Safe-U. Página estática, sin dependencias: abrir `index.html`.

Números ilustrativos, no corresponden a ninguna organización.

## Demo Banco Cordillera

`cordillera/` tiene el caso completo del taller (banco ficticio): árbol FAIR, cinco controles, curva, distribución, componentes y qué mueve el resultado. Se abre en https://joacogalermes.github.io/simulador-fair/cordillera/
